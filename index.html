02 / android - sapphire (Redmi Note 13 4G)

Volunteer device tree maintainer for sapphire (SM6225 / Bengal SoC) across Evolution X and LineageOS. Selected log entries from ongoing maintenance work:

feat

FastCharge system app (com.android.fastcharge)

Built a sysfs-based charging mode control app from scratch, including a persistent START_STICKY service to work around a kernel JEITA_VOTER reset that kept reverting the charge mode.

fix

Camera HAL SIGSEGV crashes

Traced crashes to GraphicBuffer ABI mismatches and a stale sceneDetection.xml; patched MiuiCamera APK at the smali level, resolving VerifyError and register allocation issues across multiple APK versions.

fix

SELinux sepolicy: genfscon conflicts

Resolved build-blocking genfscon conflicts and wrote the FastCharge app domain policy and persist.fastcharge property rules.

perf

powerhint.json / scheduler tuning

Tuned WALT and uclamp behavior following SD680-class conservative mid-table frequency anchoring, and diagnosed audio crackling tied to power state transitions.

feat

GKI kernel porting

Converted devicetree fragments and built a standalone kernel with corrected clang/LLVM flags, resolving Soong build errors in the process.
